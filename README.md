# GoalZone – Football News Website

A responsive frontend clone of GOAL.com built with HTML, Tailwind CSS, and JavaScript.

## Features

- Responsive Header with Search & Mobile Menu
- Breaking News Ticker
- Featured & Secondary News Stories
- Latest News Section
- Team News with Logos
- Live Scores
- Video Section
- Dark / Light Mode
- News Page with Category Filters
- Fully Responsive Design

## Technologies

- HTML5
- Tailwind CSS
- JavaScript

## How to Run

1. Clone the repository:
git clone https://github.com/BahRollings/GoalZone.git
2. Open index.html in your browser
or use Live Server in VS Code.
